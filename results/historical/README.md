# Historical submission evidence

These submission artifacts are preserved from source revision `057d991`. `coursework/` corresponds to `code/output/`; `final/`
corresponds to `code/final/plots/`. Original filenames and nested experiment names
are retained to trace figures to the submitted report.

`manifest.json` records the full source commit, original and current paths,
SHA-256 digests, byte sizes and artifact kinds for all 80 files (72 PNGs and eight
Git-LFS pointer files). The `.pkl` files are pointer text, not numerical payloads.
The archive does not establish reproducibility of reported measurements.

New outputs belong in ignored `artifacts/`; see [artifact documentation](../../docs/artifacts.md).

`ex4-console-transcript.txt` and `ex5-console-transcript.txt` preserve the
trailing console-output strings extracted from those exercise files at the same revision.
They are historical text evidence, not new validation results; the 80-file manifest
covers the original binary/pointer artifacts, not these extracted text excerpts.
